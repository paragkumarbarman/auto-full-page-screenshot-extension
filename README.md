# ⚡ Auto Full Page Screenshot & Copy - Chrome Extension (v1.0.1)

> **Developer:** PARAG KUMAR BARMAN  
> **Website:** [https://barman-it-solutions.vercel.app/](https://barman-it-solutions.vercel.app/)  
> **Version:** 1.0.1  

Chrome Extension for taking **1-click full page auto-scrolling screenshots** and copying them **directly to your clipboard** so you can paste (`Ctrl + V`) anywhere instantly!

---

## ✨ Features in v1.0.1

- 📸 **1-Click Full Page Auto-Scroll**: Scrolls the entire page automatically (works on standard websites AND inner scroll containers like Gemini Apps, Gmail, YouTube, etc.).
- 📋 **Direct Copy to Clipboard**: Screenshot image is automatically copied to your clipboard so you can paste (`Ctrl + V`) into WhatsApp, Photoshop, Slack, Word, Docs, etc.
- 🧠 **Smart Sticky Header Hiding**: Automatically hides sticky/fixed headers while scrolling so headers aren't duplicated in your final screenshot.
- 🔐 **Author Security Signature**: Embedded steganographic digital signature protecting code authorship by PARAG KUMAR BARMAN.
- 🖼️ **Retina & High-Res Support**: Preserves exact device pixel ratio (DPR) crisp quality.
- ⬇️ **Download Option**: Provides a download button to save the screenshot as a `.png` file.
- 👨‍💻 **Developer Credit**: Includes clickable developer credit linking to [PARAG KUMAR BARMAN's Portfolio](https://barman-it-solutions.vercel.app/).

---

## 🛠️ Chrome Me Extension Kaise Install / Update Kare

1. Open Chrome browser and go to: `chrome://extensions/`
2. Top-right corner me **Developer mode** toggle turn **ON** kare.
3. Agar pehle se installed hai to extension card me **🔄 Reload** icon par click kare.
4. Agar new install kar rahe ho to **Load unpacked** button par click karke Select kare:  
   `H:\Chrome Extensions\capturefullscrollablepage`
